# Elemental-era artwork

Moved out of `web/public/art/` when Prototype A's artwork landed. These are
the eight element icons, four leader portraits, and the old card back and
frame, plus the PNG renders used to check the sigils at 16px and 96px.

Still referenced by `src/ui` and `src/v3/ui`, which implement the
eight-element game. That code is no longer served (`main.tsx` serves
`src/proto`) but is still tested, so these assets are kept rather than
deleted -- and this project has no version control, so a delete here is
permanent.

If the eight-element game is ever retired for good, this folder and those
two UI trees go together.
